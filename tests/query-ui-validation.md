### 2026-11-09 搜索标签与输入法误登记验证

- 问题复现（本机 18401 端口，Chromium）：在法术中模拟输入法上屏“火”，400ms 后上屏“球”，60ms 后再上屏“术”，未按 Enter，URL 却成为 `q=火&q=火球术`，“名称：火”出现为标签。原因是保留的搜索由 URL 最后一个 `q` 与输入框文字比较推断，而 URL 在 160ms 防抖后才更新：第二次上屏时 URL 仍是“火”、输入框已是“火球”，两者不等，“火”被当作保留的搜索。普通键盘输入的间隔短于 160ms 时同样会触发，输入法连续上屏最容易遇到。
- 修正后同一序列的 URL 为 `q=火球术`，没有标签；Enter 后“名称：火球术”成为标签，接着上屏“塑能”时 URL 为 `q=火球术&q=塑能`，只有前者是标签。保留的搜索改为页面状态；另外忽略 `keyCode` 229 的按键，Safari 在合成结束后才送出确认合成的 Enter。
