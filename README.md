5echm-web 是 5e 不全书的本地网页镜像，不可修改；5e-anna 基于其内容开展分析。


本目录作为独立 Git 仓库维护。原文镜像位于同级 `5echm-web/`，源码与生成数据分开管理。

- [DESIGN.md](DESIGN.md)：产品愿景与成功标准。
- [AGENTS.md](AGENTS.md)：工作约定。
- [使用.md](使用.md)：环境准备、数据重建、查询与测试。
- [整理规划.md](整理规划.md)：数据结构与提取规划。
- `scripts/`、`web/`、`tests/`：提取与查询源码、查询界面和测试。

`data/`、`.venv/` 和缓存保留在本地，不纳入版本管理。新环境按使用说明安装依赖、准备原文镜像并生成数据后，再执行完整测试。
