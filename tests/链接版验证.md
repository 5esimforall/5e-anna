# 链接版验证

## 可重复运行的检查

`make check` 运行单元测试、浏览器回归与数据审计。安装依赖、端口配置及报告位置见[使用说明](../使用.md#自动化验证)。浏览器测试自行启动和停止隔离的本机服务，不修改原文或正在使用的浏览器设置。

| 检查层 | 自动断言 |
| --- | --- |
| 提取与生成 | 规范化文本到原 DOM 的 UTF-16 偏移；注入前原文件字节一致；重复构建一致；原文变化、目录重叠、空白定义的拒绝与报告 |
| 服务生命周期 | 两端口启动、配置端口传递、未知条目与无内容条目的明确错误、Host／路径限制、文件哈希失配；第二端口冲突释放第一端口；SIGINT／SIGTERM 同时停止 |
| 浏览器排版 | 法术页、武器表、怪物数据卡、引用表；1280px／390px 视口下，页首与中段共 16 组原版／链接版像素比较；可见文本与元素几何位置一致 |
| 浏览器导航 | 定义进入准确的 anna 记录；详情打开阅读器并定位；刷新后保留条目；在 iframe 内点击定义返回顶层 anna；引用留在链接版并到达目标 ID |
| 动态交互 | 速查表分页、筛选后恢复原引用；合成夹具中的表格节点搬移、窄屏折行、滚动和键盘焦点保持；点击区域与文字坐标对齐 |

排版基准是本次测试同时渲染的原版页面，不使用人工批准的历史截图。像素比较不设容差；布局改变、浏览器未捕获异常或链接绑定警告均导致失败。原版／链接版截图随报告保存；发生视觉差异时增加差异图，失败时保留 trace。

## 2026-11-06 运行结果

原文快照为 `c1425c8`，全量构建覆盖 7,479 个内容页。执行 `make build` 后运行 `make check`：94 项单元／夹具测试与 12 项 Chromium 浏览器测试全部通过；16 组截图比较均为 0 个差异像素。数据审计的 SQLite 完整性、外键和 CSV／SQL 一致性检查通过，原文仓库工作区保持干净。

浏览器回归曾复现并约束以下问题：速查表分页移除行后排序访问失效 Range；阅读器刷新时丢弃条目锚点。链接层现在按原始节点顺序组织键盘入口，并保留文本节点引用以适应搬移；阅读器附加脚本保存条目片段。滚动和重排时复用可聚焦链接，同时更新其坐标。

先前人工实机观察确认了警报术定义与 anna 的往返入口。后续验证以自动测试为主；合成夹具只证明指定的 DOM 变化，真实原文样本证明上述页面与操作，不代表所有页面均经过浏览器检查。

## 覆盖边界

本次生成 31,167 条定义记录，其中 31,150 条具有可点击文字；17 条空白／无正文范围记录没有可靠定位，访问定义路由返回明确错误。另有 26 条正文提取范围为空，其中部分仍能以标题定位，保留在生成报告中供提取侧核对。

已转换 6,639 处原文链接，556 处未唯一解析的链接保留原样。普通文本、下划线术语以及尚未提取为独立条目的子能力不属于当前引用转换范围。完整待核清单位于生成的 `data/5echm-anna/anna-report.json`；测试通过不等于这些问题已完成语义审核。
