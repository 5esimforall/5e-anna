# 5e anna

anna 把 5e 不全书整理为可查询的细粒度条目，并生成与原版排版一致、可沿引用跳转的链接版不全书。产品愿景与工作流程见 [DESIGN.md](DESIGN.md)。

## 运行

```sh
make build   # 从原文快照生成数据库与链接版
make up      # 启动 anna 与链接版，Ctrl-C 一并停止
```

anna 位于 <http://127.0.0.1:8001/>，链接版位于 <http://127.0.0.1:8002/>。链接版的定义标题打开对应的 anna 条目，anna 条目可返回定义处；已唯一解析的原文引用跳到链接版内的定义。

新环境的依赖安装、端口与路径配置、审核和测试命令见[使用说明](使用.md)；链接生成范围与待核项见[链接版与联动启动](使用.md#链接版与联动启动)。

## 原文镜像

- 原文镜像位于同级的 `5echm-web/`，是独立的 Git 仓库，也供其他冒险项目引用；anna 只读取，不修改其内容。
- 镜像缺失时自动下载。已有镜像不会在启动或构建时更新：先运行 `make update` 拉取原文，再运行 `make build` 重建数据。
- `Makefile` 是工作流程的唯一实现。上层 DnD 目录的 `Makefile` 只转调本项目，同一组命令在两层都可使用。
