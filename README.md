# 5e anna

anna 把 5e 不全书整理为可查询的细粒度条目，并生成与原版排版一致、可沿引用跳转的链接版不全书。产品愿景与工作流程见 [DESIGN.md](DESIGN.md)。

## 运行

```sh
make build   # 从原文快照生成数据库与链接版
make up      # 在 8000 启动查询与阅读，Ctrl-C 停止
```

打开条目查询 [anna](http://127.0.0.1:8000/) 或不全书阅读器 [stella](http://127.0.0.1:8000/read)。阅读器提供目录、本页条目、本机全文搜索，以及目录子树内的连续阅读、自动接续、远页回收和分页跳转，正文保留原版排版；定义标题打开 anna 条目，条目可返回原文，已解析的引用在阅读器内跳到定义。两页顶栏可互相转向，接住正在看的条目，或回到各自记得的位置。应用与正文资源共用 8000 端口，正文位于 `/book/`。

新环境的依赖安装、端口与路径配置、审核和测试命令见[使用说明](使用.md)；链接生成范围与待核项见[阅读服务与正文生成](使用.md#阅读服务与正文生成)。

## 原文镜像

- 原文镜像位于同级的 `5echm-web/`，是独立的 Git 仓库，也供其他冒险项目引用；anna 只读取，不修改其内容。
- 镜像缺失时自动下载。已有镜像不会在启动或构建时更新：先运行 `make update` 拉取原文，再运行 `make build` 重建数据。
- `Makefile` 是工作流程的唯一实现。上层 DnD 目录的 `Makefile` 只转调本项目，同一组命令在两层都可使用。
