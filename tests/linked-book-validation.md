# 链接版验证

## 可重复运行的检查

`make check` 运行单元测试、浏览器回归与数据审计。安装依赖、端口配置及报告位置见[使用说明](../USAGE.md#自动化验证)。浏览器测试自行启动和停止隔离的本机服务，不修改原文或正在使用的浏览器设置。

| 检查层 | 自动断言 |
| --- | --- |
| 提取与生成 | 规范化文本到原 DOM 的 UTF-16 偏移；仅移除旧壳脚本加载，正文文字与 DOM 绑定一致；重复构建一致；原文变化、目录重叠、空白定义的拒绝与报告 |
| 服务生命周期 | 两端口启动、配置端口传递、未知条目与无内容条目的明确错误、Host／路径限制、文件哈希失配；第二端口冲突释放第一端口；SIGINT／SIGTERM 同时停止 |
| 浏览器排版 | 法术页、武器表、怪物数据卡、引用表；1280px／390px 视口下，页首与中段共 16 组原版／链接版像素比较；可见文本与元素几何位置一致 |
| 浏览器导航 | 定义进入准确的 anna 记录；详情打开阅读器并定位；刷新后保留条目；在 iframe 内点击定义另开 anna 标签页；引用在当前页面到达目标 ID |
| 整页阅读器 | 独立目录节点、重复入口、缺失目标、全文搜索分页、导航与位置恢复；窄屏抽屉、键盘焦点、消息来源拒绝、关闭存储与错误重试；旧阅读入口返回 404 |
| 阅读快照 | 原文与数据库更新后重建目录及定位；旧条目不按名称迁移；运行中重建返回 409；全文索引在同一提交内的内容变化后失效 |
| 动态交互 | 速查表分页、筛选后恢复原引用；合成夹具中的表格节点搬移、窄屏折行、滚动和键盘焦点保持；点击区域与文字坐标对齐 |
| 概念线索 | 格式嵌套顺序、部分／冲突格式、未知样式、定义／引用／示例角色、版本与来源歧义；跨目录速查发现、未高亮名称反扫、证据与导出核对；真实法术页格式引用跳转、详情证据及具名候选展开 |
| 核心规则子定义 | 夹具核对并列释义与双语规则句、括号嵌套、示例及非定义拒绝路径；真实原文核对两代掩护的父子关系及力竭等级；浏览器验证普通正文与高亮引用共同指向正确代际的独立定义 |
| 链接标记 | 默认关闭，嵌入正文与原版逐像素一致；开启后高亮范围与本页绑定的引用和定义一一对应，正文 DOM 与地址不变，浅色／深色各用一组底色；关闭后像素恢复；选择跨刷新、后续文档与其他标签页生效，存储被拒时仍可切换，不支持文字高亮的浏览器不显示开关 |

排版基准是本次测试同时渲染的原版页面，不使用人工批准的历史截图。像素比较不设容差；布局改变、浏览器未捕获异常或链接绑定警告均导致失败。原版／链接版截图随报告保存；发生视觉差异时增加差异图，失败时保留 trace。

### 暴露的缺口

1. **连续审核成本高。** 保存第一条后，第二条立即被“审核日志尚未重放”拒绝；保存第二条之前需要一次全量构建。需要在同一固定输入快照上允许批量保存，再统一重放，同时保留并发和过期依据检查。
2. **失效依赖过宽且不透明。** 当前指纹覆盖 `scripts/*.py`，工作区代码变更会使事实依据未变的逐处决策失效。需要区分解析语义版本、实际依赖和纯展示／服务变更，并展示旧新依据差异；不能通过取消校验解决。
3. **目标选择依赖人工搜索。** 坏路径案例没有自动候选，需要从原文件名、锚点和来源自行找目标。可将这些结构证据用于补充待核候选，而非按名称直接批准。
4. **缺少“定义缺失”的处理闭环。** 具名角色需要可追踪的提取问题或有证据的定义提升流程；逐处确认与非引用两种操作无法表达这种需求。
5. **审核界面仍偏诊断输出。** 需要并排展示引用上下文、候选定义、选择理由、变更差异及保存／重放状态；当前原始 JSON 不适合作为主要审核界面。

建议先补批量保存与依赖差异解释，再补候选搜寻和缺失定义队列。本轮仅记录发现，保留待核状态，未绕过校验重新批准。

## 2026-11-13 属性与技能

属性与技能成为定义条目后（见[查询界面验证](query-ui-validation.md#2026-11-13-属性与技能)），正文对它们的引用多以检定写法出现：`感知（察觉）检定`、`体质豁免`、`魅力（欺瞒或游说）检定`。本轮让写法的每个部分分别解析，并只关联自己那一种定义：括号前是属性，括号里的各项是技能，紧接“检定／豁免”之前的短名称是属性或技能，以“检定”“豁免”结尾的名称是检定本身。写法标明了种类，同名表格（PHB24《第三步：确定属性值》的“力量Strength”表）不再与属性竞争；名称没有该种定义时（`死亡豁免` 的“死亡”）按所在规则用语处理。较长名称只在另一代际有定义时（2024 正文里的 2014“智力检定”），改用其中本代际有定义的最长名称，证据记下原先的较长名称。
