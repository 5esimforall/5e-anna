# 查询界面设计与实现

查询界面围绕筛选、横向比较和原文核对组织。法术、生物、物品等视图共用工作台与阅读层，具体字段、筛选组和排序仍由服务端 schema 提供。

## 视觉规则

[Open Claude UI](https://github.com/Caho1/open-claude-ui) 提供温润表面、克制边框和清晰控件层级的设计参考。本实现没有复制其主题或引入运行时依赖；`style.css` 中的 `--anna-*` 是本地维护的语义变量，不跟随上游版本自动变化。

- `canvas` 承载导航和外壳，`surface` 承载查询区域，`paper` 承载结果和阅读内容。边框划分区域，阴影只用于窄屏浮层。
- `brand` 与 `selected` 使用酒红色表达导航、局部筛选与当前条目；`focus` 单独表达键盘焦点；`warning`、`success` 表达已有的数据状态。
- 多选项保留方形选中标记；互斥条件使用分段按钮。隐式全选保持中性色，显式筛选使用强调色。颜色不替代文字、符号或可访问状态。
- 结果保留表格与各分类的列顺序。表头和名称列固定；英文名、来源、规则版本保持可读，属性通过横向滚动查看。
- 各视图的前两组多选和 CR 范围优先显示，其余领域条件放在“更多筛选条件”中。带相应参数的直接链接自动展开；已选条件始终独立显示。
- 控件使用短时颜色反馈；遵循 `prefers-reduced-motion`。不引入聊天气泡、装饰性加载光效、专有字体或网络字体。

## 阅读与状态

`detail.js` 管理同一个原生 `dialog`：CSS 视口宽度达到 1200px 时使用 `show()` 作为非模态第三栏，更窄时使用 `showModal()` 作为阅读层。两端切换保留内容、滚动位置和阅读层内的焦点。CSS 和 JavaScript 的 1200px 断点需同步修改，边界由浏览器测试约束。

结果列表可连续打开不同记录；阅读栏的箭头只浏览当前结果页，不隐式换页。当前条目不在本页时明确提示并禁用箭头。筛选或分类变化会关闭旧详情，普通分页允许保留正在阅读的条目。

URL 保存查询、筛选、排序、分页和条目身份。`history.state.anna` 保存本标签页的面板展开、列表及详情滚动、详情栏目和返回焦点目标；不把这些临时偏好写进共享 URL。刷新和历史导航在数据加载后恢复位置。新查询回到列表顶部，打开和关闭详情不主动移动列表。

每次条目请求有递增序号；旧请求迟到或关闭后返回时，不覆盖当前阅读内容。读取失败保留关闭与重试入口，不把失败显示为空正文。

## 键盘与文案

- `/` 聚焦搜索，输入法合成和窄屏模态阅读期间不抢夺输入。
- 结果名称上的上下方向键移动焦点，Enter 打开条目。
- 详情栏目使用左右方向键、Home、End 切换，只有当前栏目进入 Tab 顺序。
- Esc 关闭阅读层并返回结果入口；宽屏 F6 在列表和详情之间切换。
- 窄屏 Tab 和 Shift+Tab 在可见、可用的阅读控件之间循环。

本轮新增文案集中在 `app.js` 的 `annaUiLabels` 中，同时维护 `zh` 和 `en`。共享原文链接与审核术语继续使用 `link-labels.js`；本次不增加整站语言切换功能。

操作说明见[使用说明](../使用.md#查询与分析)，测试覆盖和实测结果见[查询界面验证](../tests/查询界面验证.md)。
