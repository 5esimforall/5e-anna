5echm-web 是 5e 不全书的本地网页镜像，不可修改；5e-anna 基于其内容开展分析。


本目录作为独立 Git 仓库维护，并管理原文下载、离线浏览、分析构建与查询的完整流程。原文镜像保留在同级 `5echm-web/`，作为其他冒险项目也可引用的共享资源，保持独立 Git 仓库；anna 不修改其内容。

`Makefile` 是工作流程的唯一实现，上层 DnD 的 `Makefile` 只转调本项目。同一组命令可在两层使用；启动与分析不会拉取已有镜像的更新，更新须显式运行 `make update`。路径配置与命令见[使用说明](使用.md)。

- [DESIGN.md](DESIGN.md)：产品愿景与成功标准。
- [AGENTS.md](AGENTS.md)：工作约定。
- [使用.md](使用.md)：环境准备、数据重建、查询与测试。
- [整理规划.md](整理规划.md)：数据结构与提取规划。
- `Makefile`：原文管理、服务、构建和验证命令。
- `scripts/`、`web/`、`tests/`：提取与查询源码、查询界面和测试。

`data/`、`.venv/` 和 `.cache/` 搜索缓存保留在本地，不纳入版本管理。新环境按使用说明安装依赖、准备原文镜像并生成数据后，再执行完整测试。
