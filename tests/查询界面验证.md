# 查询界面验证

## 验证范围

查询工作台共用视觉规则，继续消费原有的分类 schema 和条目 API。验证区分真实语料上的浏览器行为、注入故障及合成输入事件，避免把样例成功等同于全库语义正确。

| 范围 | 自动检查 |
| --- | --- |
| 法术筛选 | 环阶多选、清空产生空结果、专注互斥条件、未知值、折叠后已选条件可见；结果 ID 序列与相同查询的 API 响应一致 |
| 筛选收起 | 1280×800 与 390×844 下筛选区默认收起，URL 条件显示为可移除的已选条件，首条结果位于视口上方 70% 内，宽屏结果表不低于视口一半；展开状态经刷新恢复，新访问重新收起 |
| 等待状态 | 拦截分类切换后的条目请求：等待期间保留旧表头与等列旧行，计数与分页随之变淡，翻页与导出禁用；响应后表头、行与分页同时更新并回到列表顶部 |
| 目录与紧凑格子 | 每个分类视图在目录中出现且仅出现一次，全部条目与法术居首，怪物、物品、角色选项、规则四组可按组名访问；390px 下目录展平为单行。法术“成分”字形条与言语／材料筛选的 API 结果一致，读屏文本为完整名称与状态，CSV 导出保留五个布尔列 |
| 阅读与核对模式 | 默认收起审核列、引用审核入口、审核筛选和审核栏目，阅读栏显示核对摘要；摘要开启核对模式并聚焦证据栏目；模式经刷新保留且不进入 URL；关闭时回到正文且不关闭条目；URL 中的审核筛选在阅读模式下仍可见、可移除 |
| 同名版本并排 | 默认结果按同名候选组合并：所有分页的版本 ID 恰好覆盖扁平结果一次，每行位于其显示版本在扁平排序中的位置；5r／5e 优先、规则版本筛选、`versions=each` 与非法参数；职业能力不跨职业合并；以太化学派差异只在“学派”列标出，火球术成分写法差异不算差异；导出始终一个版本一行。浏览器检查版本标签打开对应条目、行选中与本页位置、阅读栏版本对照与版本切换保留栏目、优先显示不关闭阅读栏、取消合并写入 URL 并可经历史返回 |
| 窄屏列表 | 390px 下表头隐藏，单元格以伪元素显示列名，结果区无横向滚动，名称独占一行；恢复宽屏后表头重现 |
| 分类共用 | 遍历元数据中的所有分类及全部条目视图，核对列数和领域筛选组；在 1440px 打开条目，在 390px 检查页面不横向溢出；单独验证 CR 范围与同调条件 |
| 连续查阅 | 宽屏非模态、当前行标记、本页相邻条目、证据入口、列表位置保持、筛选或分类变化时关闭旧详情 |
| 历史恢复 | 分页、每页数量、排序方向、筛选折叠、详情栏目、列表和阅读层滚动；刷新及前进后退；历史返回后的键盘焦点 |
| 键盘与窄屏 | 模态焦点循环、Esc 返回、F6 切换、栏目方向键与 Home／End；跨断点保留条目和焦点 |
| 边界尺寸 | 法术阅读样本检查 320、760、761、1199、1200、1280、1920px；模态切换符合断点，正文不横向溢出，减少动效偏好生效 |
| 故障与竞态 | 注入查询／详情 503，检查错误与重试，查询失败同时清空计数与分页；不存在的条目 ID；延迟旧条目响应不能覆盖新条目 |
| 中文输入 | 合成 composition 事件与 Enter 不提交中间文本，组合结束后只查询最终文本；此项不是系统输入法实机测试 |

上述检查位于 `browser/query.spec.cjs`。既有 `browser/links.spec.cjs` 继续验证定义与原文往返、引用目标、阅读器恢复和原文／链接版像素一致性。未捕获的 JavaScript 异常会使两套浏览器检查失败。
