# 查询界面设计与实现

查询界面围绕筛选、横向比较和原文核对组织。法术、生物、物品等视图共用工作台与阅读层，具体字段、筛选组和排序仍由服务端 schema 提供。

## 视觉规则

查询界面同时承载两种内容：不全书本身的规则文字，以及 anna 从中提取、推断和核对出的结构。视觉规则让读者一眼分清两者，并把审核细节留给需要它的时候。

- 书的内容使用衬线字体：分类标题、条目中英文名、阅读栏标题与正文。工作台控件、筛选和表格数值使用无衬线字体。两套字体都取自系统字体栈（`--anna-serif` 与 `--anna-sans`），不引入网络字体。
- 银灰承担工作台外壳：`canvas` 承载导航和顶栏，`surface` 承载查询区域，`paper` 承载结果和阅读内容。边框划分区域，阴影只用于窄屏浮层。
- 酒红（`brand`）只表达 anna 加在原文上的东西：当前分类与条目、已选筛选、提取字段及其证据。`focus` 单独表达键盘焦点；`warning`、`success` 表达已有的数据状态。颜色不替代文字、符号或可访问状态。
- 多选项保留方形选中标记；互斥条件使用分段按钮。隐式全选保持中性色，显式筛选使用强调色。
- 左侧目录按查阅方式分为法术、怪物、物品、角色选项和规则；未列入分组的视图归入“其他”，不会消失。窄屏时目录展平为一行横向滚动条。
- 结果保留表格与各分类的列顺序。表头和名称列固定；英文名、来源、规则版本保持可读，属性通过横向滚动查看。法术的言语、姿势、材料合并为“成分”列，仪式与专注合并为“仪式/专注”列，以字形条显示：具备的成分为实色，不具备的变淡，未提取与冲突分别标出，特殊材料附 `*`。读屏读出完整名称与状态；筛选和 CSV 导出仍逐项保留五个布尔字段（schema 的 `composites` 与 `export_columns`）。
- 查询区宽度不足 640px 时，结果改为列表：名称独占一行，其余属性以“列名 值”依次排列，不再横向滚动；排序使用结果栏的排序选择。
- 筛选区默认收起，首屏留给结果；已选条件始终在筛选区外独立显示，可逐项移除。展开后，各视图的前两组多选和 CR 范围优先显示，其余领域条件放在“更多筛选条件”中，带相应参数的直接链接自动展开该部分。
- 控件使用短时颜色反馈；遵循 `prefers-reduced-motion`。不引入聊天气泡、装饰性加载光效、专有字体或网络字体。

## 同名版本并排

同一法术、生物或物品常在多个版次和规则代际中各有一条记录。逐行罗列会让同名条目相邻重复，版本之间的规则差异要隔行对照才能发现。默认结果因此把同名候选组（`identity_candidates`）中的版本合为一行，回答“这件东西有哪些版本、它们有何不同”。

- 名称下列出各版本标签（来源缩写与规则版本），待核版本用虚线；点击标签打开对应条目，所在行保持选中。行内数值来自优先规则版本：默认 5r 优先，其次 5e，最后待核；同一规则版本中取当前排序靠前者。“优先显示”可改为 5e 优先。
- 某一列的取值在版本间不同时，显示值加点状下划线，其他版本的值列在下方。比较前统一空白与全角半角；未提取、冲突或不适用的值不算差异。名称、来源、版本、类型、分类依据与旧版标记标识版本本身，不参与比较。
- 合并只在当前筛选结果内进行：筛选决定哪些版本存在，每组出现在其优先版本的排序位置。计数同时给出行数与版本数，分批加载按行进行。
- 只有英文名能标识同一出版对象的类型才并排：法术、物品、生物、专长、种族、背景、职业、子职、载具、状态等（`browse.STACKABLE_TYPES`）。职业能力按职业限定作用域，规则与资料段落常共用通用标题，同名时仍各占一行。
- 取消“合并同名版本”回到一个版本一行（`versions=each`）；5e 优先记为 `prefer=5e`。两者写入 URL 与历史，切换时阅读栏保持打开。CSV 导出始终一个版本一行。
- 阅读栏标题下列出同组全部版本，不受当前筛选限制；“版本对照”栏目逐字段比较，不同字段在前，相同或未提取的字段折叠。在版本间切换时保留当前栏目。同组关系是候选，不代表同一规则身份。

## 阅读模式与核对模式

默认的阅读模式服务于查阅规则：分类依据与旧版标记的筛选、“分类依据”“旧版标记”列、引用审核工作台入口，以及阅读栏中的证据、概念线索、有效引用和待核栏目都收起。阅读栏底部保留一行核对摘要，列出这些栏目的数量；点击摘要即开启核对模式并打开证据栏目。条目被明确标旧时，阅读栏仍显示旧版标记；字段冲突在两种模式下都显示。

顶栏的“核对”开关切换两种模式。选择保存在当前站点的 `localStorage`（`anna.audit`），同源标签页同步，不写入查询 URL；存储被禁止时仍可在当前页切换。共享链接中已带的审核筛选（分类依据、旧版标记、仅字段冲突、包含未分类段落）在阅读模式下照常生效，筛选区继续显示对应分组，便于核对和移除。关闭核对模式时，若阅读栏停在审核栏目，则回到正文，不关闭条目。

## 品牌头像与网站图标

favicon 使用银白短发、酒红后掠龙角的 Anna 头像，主图与生成提示词保存在 `assets/branding/`。运行 `uv run scripts/build_icons.py` 可重建透明 PNG（16、32、48px）、多尺寸 ICO（16–256px）和应用内头像 `web/anna-logo.png`（128px），并在 `output/imagegen/anna-favicon-preview.png` 输出浅／深底原尺寸与像素放大对照。Pillow 仅用于离线导出，运行服务无需安装。

查询页声明各尺寸 PNG 和 ICO，页面文本视图共用 ICO；服务仅开放这些明确的静态路径，不开放素材目录。

查询页左上角以 36px 正方形显示透明头像，128px 素材兼顾高像素密度屏幕；固定宽高避免加载时位移，保持原图比例与完整龙角。头像与应用名共同构成首页链接，图片使用空替代文本，避免读屏重复播报；窄屏保持头像尺寸，不挤压变形。

## 浅色、深色与系统外观

右上角采用与不全书相近的图标按钮：单击在当前实际浅色／深色之间切换，太阳、月亮和显示器分别表示浅色、深色和跟随系统。默认跟随系统；Shift+点击、Shift+Enter 或 Shift+空格可恢复跟随系统，悬停提示说明当前状态、下一步操作和快捷键。页数、版本及“本地只读”状态信息不再占据顶部空间。

明确选择保存在当前站点的 `localStorage`（`anna.theme`）；恢复跟随系统会移除此值。主题不写入查询 URL 或历史快照，切换时保留筛选、阅读位置与打开的条目。同源标签页同步选择，系统外观变化仅影响跟随系统的页面；浏览器禁止存储时仍可在当前页切换。

`theme.js` 在样式表之前执行，首屏即应用保存的选择，并独立提供中英文主题控件文案；查询 API 失败不影响外观切换。`style.css` 以 `data-theme` 覆盖语义颜色，同时设置原生控件的 `color-scheme`；错误、警告、成功、高亮与遮罩各自使用配套前景／背景色。深色沿用暖灰表面和提亮的酒红强调色，不反相头像或页面。

anna 的页面文本视图共用主题设置。链接版不全书保持原文呈现，不跟随 anna 改写书籍样式。

## 原文排版与字段批注

提取文本保留了文字，却丢掉了表格、标题和强调：数据卡的属性表会压成一串“调整豁免调整豁免”。阅读栏的“正文”因此显示条目所在原文页面的排版，并把 anna 读出的字段作为批注，标在它们所依据的文字上。

- `scripts/entry_layout.py` 读取原文镜像中的页面，确认文件哈希和解析文本都与数据库快照一致，再按条目的文本范围序列化相交的 DOM。来源标签映射到一小组无行为的元素（段落、标题、强调、列表、表格等），只保留表格的 `colspan`／`rowspan`；脚本、图像、链接地址、内联样式与原有类名一律不复制。不超过 12 个字的表格单元格保持整行，长单元格按正文换行。条目标题行已由阅读栏标题显示，排版从标题之后开始。
- 字段证据（`facts`）与已解析的有效引用使用提取时的同一套规范文本偏移：证据范围包上 `mark.note`，引用变为打开目标条目的按钮。原文明示的证据用实线下划线，上下文推得的用虚线。证据跨元素时在每一侧分别标记。
- 批注按首个证据在正文中的位置排列；证据来自速查表等其他页面的字段排在最后，标为“证据不在本段原文”。悬停或聚焦批注时，对应文字高亮，反之亦然；点击批注将文字滚入视野。阅读栏内容宽度达到 600px 时批注排在页边，更窄时列在正文之后。类型、规则版本、来源等标识版本本身的字段不作批注。
- `/api/entry-layout` 在原文缺失、已更新或范围为空时返回相应状态。阅读栏先显示提取文本，排版到达后替换；无法排版时保留提取文本并说明原因，不显示局部结果。链接版仍是逐字节保留的原文，此处的排版是派生视图，不回写原文。

## 分批加载

结果列表不分页，而是随滚动分批加载：浏览一长串按环阶排好的法术时不必停下来点击翻页，结果栏也省下了每页数量与页码控件。

- `/api/entries` 以 `offset` 与 `limit` 读取一段结果，每批 150 行；一次最多 1,500 行，供恢复历史位置使用。合并同名版本时按行计数。
- 滚动到距列表末尾 600px 内时自动加载下一批。底部同时保留“继续加载”按钮，供键盘和读屏使用；在最后一个名称上按下方向键，也会加载下一批并把焦点移入。底栏以状态区播报“已显示 300 / 933 行”，全部加载后改为“已全部显示”。
- 自动加载、按钮、方向键和阅读栏箭头共用同一个进行中的请求，不会重复读取同一批。追加的行不使已有结果变淡；追加失败时保留已加载的行，底部显示错误，按钮变为“重新加载”，并暂停自动加载直到再次点击。
- 阅读栏的“下一条”跨过已加载的末尾时先加载下一批，再打开下一行；位置显示为“第 151 / 933 行”。打开的条目若不在已加载的行中，提示“不在已加载的结果中”。
- 加载位置不进入 URL。已加载行数与列表滚动位置记在 `history.state.anna`，刷新和前进后退时一次读回相同行数并恢复位置。旧链接中的 `page`、`size` 参数在载入时移除，其余查询条件保留。
- 不做只渲染可见行的虚拟滚动，固定表头、固定名称列与焦点行为保持简单。最长的“全部条目”全部加载后仍可流畅滚动，实测见[查询界面验证](../tests/查询界面验证.md)。

## 阅读与状态

`detail.js` 管理同一个原生 `dialog`：CSS 视口宽度达到 1200px 时使用 `show()` 作为非模态第三栏，更窄时使用 `showModal()` 作为阅读层。两端切换保留内容、滚动位置和阅读层内的焦点。CSS 和 JavaScript 的 1200px 断点需同步修改，边界由浏览器测试约束。

结果列表可连续打开不同记录。筛选或分类变化会关闭旧详情；加载更多结果、切换合并或优先显示时保留正在阅读的条目。

URL 保存查询、筛选、排序、版本显示方式和条目身份。`history.state.anna` 保存本标签页的面板展开、已加载行数、列表及详情滚动、详情栏目和返回焦点目标；不把这些临时偏好写进共享 URL。刷新和历史导航在数据加载后恢复位置。新查询回到列表顶部，打开和关闭详情不主动移动列表。

查询等待期间，结果区保留上一次完成的表头、行和计数，整体变淡且不可操作，继续加载与导出暂时禁用。新响应到达后，表头、首批行和计数一次替换，分类切换时不会先清空表格或混排新旧列。查询失败则清空行和计数，只保留错误提示与恢复入口。

每次条目请求有递增序号；旧请求迟到或关闭后返回时，不覆盖当前阅读内容。读取失败保留关闭与重试入口，不把失败显示为空正文。

## 键盘与文案

- `/` 聚焦搜索，输入法合成和窄屏模态阅读期间不抢夺输入。
- 结果名称上的上下方向键移动焦点，Enter 打开条目。
- 详情栏目使用左右方向键、Home、End 切换，只有当前栏目进入 Tab 顺序。
- Esc 关闭阅读层并返回结果入口；宽屏 F6 在列表和详情之间切换。
- 窄屏 Tab 和 Shift+Tab 在可见、可用的阅读控件之间循环。

本轮新增文案集中在 `app.js` 的 `annaUiLabels` 中，同时维护 `zh` 和 `en`。共享原文链接与审核术语继续使用 `link-labels.js`；本次不增加整站语言切换功能。

操作说明见[使用说明](../使用.md#查询与分析)，测试覆盖和实测结果见[查询界面验证](../tests/查询界面验证.md)。
