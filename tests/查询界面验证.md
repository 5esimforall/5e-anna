# 查询界面验证

## 验证范围

查询工作台共用视觉规则，继续消费原有的分类 schema 和条目 API。验证区分真实语料上的浏览器行为、注入故障及合成输入事件，避免把样例成功等同于全库语义正确。

| 范围 | 自动检查 |
| --- | --- |
| 法术筛选 | 环阶多选、清空产生空结果、专注互斥条件、未知值、折叠后已选条件可见；结果 ID 序列与相同查询的 API 响应一致 |
| 分类共用 | 遍历元数据中的所有分类及全部条目视图，核对列数和领域筛选组；在 1440px 打开条目，在 390px 检查页面不横向溢出；单独验证 CR 范围与同调条件 |
| 连续查阅 | 宽屏非模态、当前行标记、本页相邻条目、证据入口、列表位置保持、筛选或分类变化时关闭旧详情 |
| 历史恢复 | 分页、每页数量、排序方向、筛选折叠、详情栏目、列表和阅读层滚动；刷新及前进后退；历史返回后的键盘焦点 |
| 键盘与窄屏 | 模态焦点循环、Esc 返回、F6 切换、栏目方向键与 Home／End；跨断点保留条目和焦点 |
| 边界尺寸 | 法术阅读样本检查 320、760、761、1199、1200、1280、1920px；模态切换符合断点，正文不横向溢出，减少动效偏好生效 |
| 故障与竞态 | 注入查询／详情 503，检查错误与重试；不存在的条目 ID；延迟旧条目响应不能覆盖新条目 |
| 中文输入 | 合成 composition 事件与 Enter 不提交中间文本，组合结束后只查询最终文本；此项不是系统输入法实机测试 |

上述检查位于 `browser/query.spec.cjs`。既有 `browser/links.spec.cjs` 继续验证定义与原文往返、引用目标、阅读器恢复和原文／链接版像素一致性。未捕获的 JavaScript 异常会使两套浏览器检查失败。

## 2026-11-07 运行结果

本次从原文快照 `c1425c8` 的 7,479 个内容页构建独立测试产物，未替换默认数据库和链接版，也未重启既有开发服务。初次默认全量检查被数据库／审核日志快照不一致阻止，后续通过独立完整构建与发布快照校验完成回归，没有绕过校验。

最终结果：

- `make test-unit`：113 项单元／夹具检查通过。
- 完整 Chromium 浏览器回归：23 项通过，其中 10 项为查询工作台检查、13 项为既有链接与排版检查。
- 16 组原文／链接版像素比较全部通过，差异为零。
- 独立全量数据审计：SQLite 完整性为 `ok`，解析错误、外键错误、CSV／SQL 差异和概念结构错误均为零。语义待核记录仍按原有规则保留。
- `node --check web/app.js`、`node --check web/detail.js` 与 `git diff --check` 通过。

检查过程中复现并修复了窄屏 Tab 焦点离开阅读层、浏览器历史返回后焦点落到页面而非当前详情栏目、连续查阅时历史返回目标被新条目覆盖的问题。对应断言保留在回归中。

应用内浏览器另行观察了实际运行站点的 1440×900 法术页：环阶一／二环多选、结果与阅读分栏、正文和字段证据；390×844 下检查全屏阅读、返回结果与内容换行。结束后清除测试筛选、关闭阅读层并恢复浏览器视口。实机截图为 `output/playwright/anna-spell-workbench.jpg` 和 `output/playwright/anna-mobile-reader.jpg`。其余分类与断点的覆盖来自自动化检查，不宣称每条正文都经过人工视觉检查。

## 复现与产物

常规工作仍使用 `make check`。需要保留现有运行数据时，在项目根目录使用独立输出：

```sh
.venv/bin/python scripts/build.py --output output/playwright/visual-data/extracted
.venv/bin/python scripts/linked_book.py \
  --db output/playwright/visual-data/extracted/catalog.sqlite \
  --output output/playwright/visual-data/book
make test-unit
ANNA_E2E_DB="$PWD/output/playwright/visual-data/extracted/catalog.sqlite" \
ANNA_E2E_BOOK="$PWD/output/playwright/visual-data/book" \
  npm run test:browser
.venv/bin/python scripts/audit.py \
  --db output/playwright/visual-data/extracted/catalog.sqlite
```

测试服务仍检查原文、数据库、审核日志和生成文件是否配套，使用独立端口并在结束时退出。依赖及端口设置见[使用说明](../使用.md#自动化验证)。浏览器需要本机启动权限；本次 Chromium 启动被沙箱阻止后，在获准的沙箱外测试环境运行。

完整浏览器报告位于 `output/playwright/report/index.html`，逐项截图位于 `output/playwright/results/`。本轮命令输出另存为 `output/playwright/unit-visual.log`、`full-browser-visual.log`、`audit-visual.log`。这些产物与独立测试数据均为本地生成文件，不入库。
