### 数据观察

输入与保存的旧产物基线一致。提取差异为 69 条类型变化、4 条新增；PHB14《施展法术》不再被当成法术，相关施法标题与术语定义进入规则。构建产生 4,748 条规则知识观察、703 条“获取路径×授予×使用分支×法术”选项，覆盖 12 个获取入口；这些是本次观察值，不作为写死的测试门槛。

语义查询只消费完整解析的获取路径。效果端的部分解析仍在详情显露，不因为获取路径完整而隐藏。全部观察未经人工核准；未解析句式和通则歧义仍有较大范围，不能将上述数量解释为全库规则完成度。

### 检查职责

- 单元和 API 回归：数量／条件／分支语义、证据切片、审核重放、背景限制、查询与单链导出一致性。
- 自动化浏览器回归：组合条件、背景到法术效果、刷新恢复、导出、证据页面和 Stella 地址跳转、窄屏及键盘标签切换。
- 数据审计：SQLite 完整性、外键、CSV／SQL、概念证据、知识 JSONL 和选项投影一致性；按规范化来源汇总，保存逐条知识变化。
- 实机验收由用户负责。用户提出接手前，MCP 已观察到侍僧→魔法学徒（牧师）→疗伤术及治疗证据展示；这次局部观察不代表用户验收完成。后续不再代用户操作实际浏览器。

全库快照计数不再作为本轮查询回归的期望值。筛选计数与实际结果相互核对，叠放与分页核对完整 ID 集合及唯一性；固定规则样本中的选择数量、使用次数与骰子表达式仍作具体断言。

## 2026-11-13：条件作用域与连续阅读

本次增量改变规则链的连接方式，不以增加已解析条目数量为验收目标。效果与豁免拥有记录内身份；条件指向具体前置效果，通则关系指向字段、授予分支或效果，并保存适用条件与修改字段。阅读范围保留问题起点、已走路径和每一步证据，候选查看不改变解析或审核状态。

### 回归范围

| 验证层 | 输入与关键断言 |
|---|---|
| 语法夹具 | 等级与属性阈值的 `all`／`any`；未知合取项使整个前置保持未解析；缺失、竞争或被未解析句隔开的豁免不绑定结果 |
| 结构夹具 | 嵌套 `all`／`any`／`not` 的局部引用校验；缺失引用、类型错误、前置顺序错误与无效通则作用域被拒绝；没有宣称已从原文自动解析所有否定和嵌套条件 |
| 审核与索引夹具 | 免费修改只属于本使用分支，法术位替代分支不继承；反向查询保留范围，否决后不作为修改者；本段已解析与通则目标歧义分别保留；索引字段或内容损坏触发审计错误 |
| 实际镜像数据 | 背景限制在正向与“法术→背景→专长”反向阅读中保持，排除列表外法术；反向获取步骤保留背景限制及背景原文证据 |
| HTTP API | 普通阅读、路径阅读、条目详情与导出结果一致；伪造关系、重复节点、非法路径数据和错误法术选项返回错误 |
| 自动化浏览器 | 妖精触碰→魅惑类人→歧义豁免定义；条件对应具体效果、逐段状态、路径前进／后退与刷新；Stella 最近查询恢复原链；通则→修改者→法术继续阅读；迟到响应不重新打开已离开的标签 |

## 2026-11-13：攻击、复合条件与持续效果

本次从“角色选项授予的法术怎样命中、造成伤害、持续及结束”展开。目标、检定、结果、数值引用和后续使用各自建模，查询与阅读消费这些关系；新增法术用于检验共享句式，不用名称开启专用解析路径。获取、效果、通则目标及例外仍分别报告状态。

### 机制与拒绝边界

| 问题环节 | 有效输入与具体结果 | 拒绝、缺失或冲突输入 |
|---|---|---|
| 获取到效果 | 智者→魔法学徒（法师）→巫术箭，保留列表限制与免费／法术位分支；妖精触碰可进入塔莎狂笑术 | 列表外的侍僧不匹配巫术箭；法术位分支不借用免费分支的长休恢复 |
| 目标与判定 | 两代火焰箭、冷冻射线的目标、攻击与命中效果；区域豁免的失败全额／成功减半指向同一检定，减半引用基础伤害 | 缺少目标、竞争攻击或中间夹入未知限定不按加载顺序绑定；未知伤害尾句整句保留缺口 |
| 复合限定 | 点燃要求命中或在区域内、物件、可燃，并且未穿戴也未携带；共用属性阈值要求明确的“或” | 无对应区域时不能绑定“此锥状区域”；仅顿号的属性列表不推断为任选其一 |
| 重复豁免 | 首次失败＋法术生效＋回合结束／受伤触发重复检定；受伤优势与成功结束只绑定重复检定 | 首次和重复角色不同，不把结束法术归到首次豁免；局部引用类型、顺序或派生链接错误被拒绝；规范 JSON 序列化后链接图保持一致 |
| 持续与变化 | 2024 巫术箭后续附赠动作自动伤害独立于首击；升环只增加初始伤害；超出范围或全身掩护提前结束 | 2014 后续伤害句未明示的首击依赖保留缺口；将“无论命中”改成未支持的限定后不生成后续使用 |
| 通则与例外 | 减速、攻击优势、治疗限制与无法自行结束倒地保留局部作用域、触发及结束；专注与后续动作连接相应通则 | 通则候选歧义仍可见，不用本地效果已解析替代通则身份核对 |
| 查询与审核 | 获取条件命中同一分支，效果条件命中同一法术的同一效果；重复检定及其结果保留重复时机 | “攻击判定＋后续自动伤害”不跨效果拼接；审核依据变化后效果退出索引，获取路径仍可独立查阅；投影损坏触发审计错误 |
| 沿链与导出 | 升环→初始伤害、结束→重复豁免→首次豁免、通则作用域→局部效果；起点与焦点在刷新及导出后保留 | 非当前条目的局部效果、缺失效果和非法查询取值返回错误 |

`tests/test_spell_effects.py` 的人工句式夹具断言字段与局部引用，原文测试核对两代共享语法及背景贯通路径，并将条目改名后再次解析以排除名称门控。`tests/test_knowledge.py` 在临时数据库验证分支关联、审核失效与投影校验；`tests/test_serve.py` 比较查询、计数、排除条件、条目详情和导出。上述夹具不写真实审核日志，也不改原文镜像。

自动化浏览器回归增加快速组合效果条件、后续成本展示、局部焦点、刷新、Stella 最近查询恢复及通则返回路径。首次运行发现连续控件编辑造成多批计数查询并发，结果等待超时；计数查询改从获取选项筛选入口，控件合并连续编辑并取消过时请求，测试等待阈值保持不变。实机验收仍由用户负责，本轮未操作用户浏览器。

完整回归还捕获了阅读器历史保存的两处回退。搜索输入事件被直接传给接收 URL 的保存函数，导致刷新访问错误地址；连续滚动后立即刷新时，Chromium 使用的历史快照早于 `pagehide` 写入。修正为显式调用输入保存，并在 `beforeunload` 先保存待写状态，保留原有滚动写入合并。四项阅读位置、目录位置与搜索恢复回归通过，日志为 `output/effect-history-regression.log`。
